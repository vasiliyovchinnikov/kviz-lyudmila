# 🎀 Насколько ты знаешь Людмилу Цой?

Подарочный веб-квиз к 42-летию жены: **42 вопроса** из её настоящих архивов (Instagram + Telegram-канал «Пишет Цой»), **3 уровня сложности**, максимум **79 баллов**, облачная таблица рекордов для всех игроков.

> **🎮 Играть: [ludatsoy.ru](https://ludatsoy.ru)**

Ни одного придуманного факта — каждый вопрос снабжён источником: пост IG или выпуск канала [@pishetsoy](https://t.me/pishetsoy).

## Фичи

- 🎮 3 уровня: «Разминка» (×1) → «Знающий» (×2) → «Читал всё» (×3)
- 💾 Автосохранение прогресса (можно закрыть и вернуться) + чекпоинт после каждого уровня
- 🏆 Общий лидерборд на своём PHP-API (`board.php`): атомарная запись, rate-limit, дедуп, офлайн-очередь на клиенте
- 🛡 Модерация записей: DELETE с токеном (timing-safe сверка, секрет вне docroot)
- 📱 Мобильный дизайн: K-pop эстетика, коллаж из фото, финальная «кассета» с кадрами
- ⚡ Cache-busting версионирование, canonical redirects, expires-политика

## Стек

Чистые **HTML/CSS/JS** без фреймворков · vanilla PHP 5.4 · GitHub Actions — нет, деплой FTP/reg.ru · хостинг reg.ru

## Структура

```
├── index.html          # одна страница
├── style.css           # тёмная тема, hot pink, Unbounded/Manrope
├── app.js              # движок квиза + клиент лидерборда
├── data/quiz.json      # 42 вопроса с источниками
├── assets/photos/      # 12 кадров из архива
└── hosting/
    ├── board.php       # API: GET/POST/DELETE + модерация по токену
    └── .htaccess       # https + canonical + кэш-заголовки
```
